About Us

This is a basic, minimalistic and demo only individual web application project named as Integrated Management System that serves functionalities of different management systems.

Technology Stack:

Technologies Used so far: HTML, CSS, JavaScript, Thymeleaf, Java

Database: MySQL

AI: OllamaLLM

Project Timeline, Expectations and Summary:

[Completed] The first phase of development starts from User Management System, with Role Based Access Control in place using Spring Security. Administrators can create, update and delete users. Users are able to access profile and change account credential such as password. Users can also see their reporting manager, team members and direct subordinates if any. For logins, there would be rate limiting in place as part of system design consideration.

[Completed] The second phase of development will focus on building a Leave Management System, where employees can apply leave with appropriate application state transitions, business logic, validations, exception handling and approval hierarchy in place. For managers, during their review, they will also be alerted of any clashing applications within the team, to make an informed decision of approving or rejecting. There is also a simple custom made team calendar that shows all up to date approved applications within the team for employees and the visibility of these applications will depend on their role.

[In Progress] The last phase of development will focus on building a HR Management System, primarily targeting resume screening so I can apply some AI/ML using Python, and onboarding to link back with User Management System.

[Update] Instead of Python, Java is used for language consistency. HR users, specialising in recruiting will now have an AI Resume Reviewer feature. Developed using Spring AI, this use case allows single or multiple resume file uploads, to review candidate resumes against job description and provide rankings with analysis. There would be rate limiting and caching in place as part of system design consideration.

If time permits, I will also want to try to replace Thymeleaf with Angular as the frontend.

[Update] As part of understanding and learning Angular, I will start with one use case - reviewing candidate resume.
