About Us

This is a basic minimalistic demo individual web application project named as Integrated Management System that serves functionalities of a management system.

Technologies Used so far: HTML, CSS, Thymeleaf, Java

Project Timeline and Expectations:

The first phase of development starts with User Management System, with Role Based Access Control in place using Spring Security. Administrators can create, update and delete users. Users are able to change account credential such as password. Users can also see their reporting manager, team members and direct subordinates if any.

The second phase of development will focus on building a Leave Management System, where employees can apply leave with appropriate business logic, validation and approval hierarchy in place.

The last phase of development will focus on building a HR management system, primarily focused on resume screening so I can apply some AI/ML using Python and onboarding to link back with User Management System.

If time permits, I will also want to try to replace Thymeleaf with Angular as the frontend.
