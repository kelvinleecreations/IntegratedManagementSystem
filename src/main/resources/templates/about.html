About Us

This is a basic, minimalistic and demo only individual web application project named as Integrated Management System that serves functionalities of different management systems.

Technologies Used so far: HTML, CSS, JavaScript, Thymeleaf, Java

Database: MySQL

Project Timeline and Expectations:

The first phase of development starts from User Management System, with Role Based Access Control in place using Spring Security. Administrators can create, update and delete users. Users are able to access profile and change account credential such as password. Users can also see their reporting manager, team members and direct subordinates if any.

The second phase of development will focus on building a Leave Management System, where employees can apply leave with appropriate application state transitions, business logic, validations, exception handling and approval hierarchy in place. For managers, during their review, they will also be alerted of any clashing applications within the team, to make an informed decision of approving or rejecting. There is also a simple custom made team calendar that shows all up to date approved applications within the team for employees and the visibility of these applications will depend on their role.

The last phase of development will focus on building a HR Management System, primarily targeting resume screening so I can apply some AI/ML using Python, and onboarding to link back with User Management System.

If time permits, I will also want to try to replace Thymeleaf with Angular as the frontend.
